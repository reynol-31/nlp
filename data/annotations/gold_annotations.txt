# Gold-standard morphological annotations (manually curated for this project).
#
# Format:   word :: category :: analysis | analysis | ... [:: note]
# Analysis: lemma TAG TAG ...   (tags as in src/schema.py; omitted features are NA)
#
# Every analysis that is grammatically possible for the isolated word form under
# the project's annotation scheme is listed (context-free annotation).  The
# annotations were written from Hindi reference grammar, not from analyzer output.
#
# Categories:
#   noun_regular       productive noun classes (-आ masc, consonant masc/fem, -ई fem, -आ fem)
#   noun_irregular     exception / stem-change classes (invariant -आ masc, -ई/-ऊ masc, -इया, -ऊ/-उ fem)
#   pronoun            personal pronouns (suppletive)
#   adjective          inflecting and invariant adjectives
#   verb_regular       regular verb forms
#   verb_irregular     suppletive / irregular verb forms (करना, जाना, होना, देना, लेना, पीना ...)
#   lexical_ambiguity  forms that belong to two different lemmas
#   spelling_variant   non-canonical but common spellings (tests normalisation)
#   oov                in-scope inflection of a lemma that is NOT in the lexicon
#   out_of_scope       morphology the system does not implement (derivation, vocative, -कर ...)
